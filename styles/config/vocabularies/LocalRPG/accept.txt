# Words Vale's dictionary does not know. Each one is a product name, an acronym
# this project uses in prose, or domain vocabulary from the RPG engine. Adding a
# word here is always preferable to rewording a correct sentence.
#
# Vale loads every vocabulary under StylesPath/config/vocabularies; `.vale.ini`
# names it with `Vocab = LocalRPG`. `vale sync` merges the downloaded packages
# into this directory and leaves what is already here alone.
#
# The vocabulary also produces a Terms rule, which is switched off in `.vale.ini`
# because it demanded one capitalisation per word and fired on table data, YAML
# frontmatter values and titles. Both cases of a word are listed below wherever
# the documentation legitimately uses both.
